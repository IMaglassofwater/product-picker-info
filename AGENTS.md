# Project Guidelines

- This is a modular Python project.
- Complete only the current explicitly requested task; do not expand scope.
- Do not modify unrelated files or remove existing functionality.
- Add tests where practical when introducing business logic, then run relevant tests.
- Never fabricate scraping results, email addresses, suppliers, or market data.
- API keys must come from `.env`.
- If an external data source is unavailable, report it honestly; do not simulate success.
